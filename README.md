# CIRNET Remote

[English documentation](docs/en/index.md) · [Tài liệu tiếng Việt](docs/vi/index.md) · [Changelog](CHANGELOG.md)

Remote owns the Lab-First REST and WebSocket APIs, control authorization, assignments, projects, experiments, scheduling, leases and capture persistence. Its Rust service serves the Interface and connects to Hardware RPC 2.0 over a local endpoint. Remote selects the system candidate and its exact component inputs.
