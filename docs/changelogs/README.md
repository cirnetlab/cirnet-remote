# Remote changelog

## 0.3.0-dev.1

- Migrate the Rust REST and WebSocket service into API, domain, application and infrastructure directories.
- Build against Contracts Next and keep the existing RPC and data compatibility.
- Preserve native deployment, migrations, capture persistence and scheduler safety regression tests.
- Establish Remote Next ownership of the Windows native candidate.
- Adopt the Ecosystem, CIRNET Lab-First and FPGA target references and archive Lab-First v3.1.
- Run Windows component CI on master pushes with pinned private dependencies.
- Document the Actions secret permissions for component CI and manual candidates.
- Reproduce legacy compiler, HTTP and database fixtures from pinned Python references and run the ignored Rust regression tests.
- Exercise browser reconnect, NCAP parity, hard reload and native process cleanup in the installed candidate.

## Tiếng Việt

- Chuyển dịch vụ REST và WebSocket Rust vào các thư mục API, domain, application và infrastructure.
- Dựng cùng Contracts Next và giữ tương thích RPC cùng dữ liệu hiện có.
- Giữ triển khai native, chuyển đổi dữ liệu, lưu bản thu và bộ hồi quy an toàn bộ lập lịch.
- Xác lập quyền sở hữu ứng viên native Windows tại Remote Next.
- Áp dụng các tham chiếu kiến trúc đích Ecosystem, CIRNET Lab-First và FPGA, đồng thời lưu trữ Lab-First v3.1.
- Chạy CI thành phần Windows khi push lên master với phụ thuộc riêng tư đã ghim.
- Ghi rõ quyền của Actions secret cho CI thành phần và ứng viên chạy thủ công.
- Tái tạo fixture trình biên dịch, HTTP và cơ sở dữ liệu legacy từ nguồn tham chiếu Python đã ghim và chạy các bài hồi quy Rust bị bỏ qua mặc định.
- Kiểm tra kết nối lại của trình duyệt, đối chiếu NCAP, tải lại trang hoàn toàn và dọn tiến trình native trên ứng viên đã cài.
